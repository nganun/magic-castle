# 如何添加学习内容（不用发版）

学习内容（汉字词组、英文单词、朗诵篇目）已经和 App 版本解耦：**在仓库里改好文本文件 → push →
手机里点一下「同步最新内容」就生效，不需要重新安装 App。**

## 一、内容放在哪

```text
data/
├── version.txt              # 内容版本号（每次改动建议 +1，用于在 App 里看"内容第几版"）
├── english/                 # 英文单词
│   └── 基础/颜色单词.txt
├── hanzi/                   # 汉字与词组
│   ├── 课堂/01-中四班-上学期.txt
│   └── 主题/01-颜色.txt
└── recital/                 # 朗诵文本
    ├── 古诗/01-春晓.txt
    ├── 儿歌/01-开门.txt
    └── 故事/01-三只小猫.txt
```

规则：

| 写法 | 含义 |
|---|---|
| 目录名 `english` / `hanzi` / `recital` | 内容类型，必须是这三个之一 |
| 子目录（如 `课堂`、`古诗`） | 学期/单元，只用于整理，App 里按它折叠展示 |
| 文件名 | 分组名，可用 `01-` 这样的数字前缀决定同目录内的顺序（显示名里不含前缀） |
| 每行 | 一个词/词组（english、hanzi）或一句（recital） |
| `# id: xxx` | 分组 id。**改过名字/目录之后不要动它**，它决定 App 认不认得这个分组 |
| `# 名称：xxx` | 显示名，不写就用文件名 |
| `# 图片：开`（或 `# image: on` / `image: true`） | 该分组显示插图。汉字插图放 `assets/learning/hanzi/<词>.svg`，英文插图放 `assets/learning/vocabulary/<词>.svg` |
| `西瓜\|一种绿色水果` | 竖线后是可选注释（词义），App 在能显示词义的地方会显示它 |

> 同一分组里不要写重复的词（`english`/`hanzi` 重复会被自动去掉并给出告警）。
> 朗诵文本是有序句子，重复句是允许的（例如"你看看我，我看看你，"出现两次）。

## 二、改完之后

```bash
npm run content:images   # 给开了 image 的分组补齐缺失的插图（不会覆盖已有的人工插图）
npm run content:build     # 重新生成内置内容并检查格式（有错会直接报错并指出文件与行号）
npm test                  # 跑测试
git add -A && git commit -m "content: 新增……"
git push origin main
```

push 之后 GitHub Pages 会在约 1 分钟内完成部署（内容就托管在那里）。

> **插图说明**：汉字组的插图是手绘的艺术图（`assets/learning/hanzi/`），
> `npm run content:images` 只能在缺失时生成"字卡"占位图；
> 英文组会生成简单的色块/星星图（`assets/learning/vocabulary/`），与现有风格一致。
> 想更好看就直接把 SVG 放进对应目录覆盖即可。

## 三、手机上同步

家长设置 → **学习内容工作台** → **内容同步** 区块 → 点「同步最新内容」。

- 状态行会显示「内置内容 vX · 远程内容 vY · 上次同步时间」；
- 同步结果会列出：**新增** 了哪些分组、**更新** 了哪些、**保留本地修改** 了哪些、
  **随官方移除** 了哪些；
- 如果你在这个分组里自己改过内容，同步会**保留你的版本**（并在结果里点名），不会被官方覆盖；
- 想彻底回到官方版本，点「恢复官方内容」。

## 三之二、页面上的"篇目"浏览器

朗诵小舞台与汉字魔法的页面顶部各有一条**按目录分层的篇目浏览器**（代替了以前那条把所有篇目平铺出来的旧横条）：

```text
朗诵篇目  全部篇目
[📁 儿歌 9 篇] [📁 古诗 2 篇] [📁 故事 3 篇]     ← 根层：目录
```

点进「故事」：

```text
朗诵篇目  朗诵篇目 / 故事
[.. 上一层] [美食播报] [三只小猫] [小象生病了]    ← 二层：文章
```

- **目录名、层级、篇数全部来自内容**，代码里没有写死任何关键词：你在 `data/recital/`（或
  `data/hanzi/`、`data/english/`）下改名、加目录、删目录，同步后浏览器立刻跟着变。
- 点目录进去，点「.. 上一层」退回；点文章/分组即切换到该篇并回到第一关/第一句。
- 目录可以有多层（`data/recital/古诗/春天/春晓.txt` → 古诗 → 春天 → 春晓）。

### 在 App 里调整目录

- **改单篇归属**：工作台里编辑分组 → 「所属目录」输入框（可用 `/` 分层）。留空 = 未分类。
- **整个目录改名**：工作台里目录标题右侧的「改名」按钮，会连同子目录一起改。
- **新增目录**：把某篇的「所属目录」填成新名字即可。
- **删除目录**：把该目录下各篇的「所属目录」清空（它们会移到"未分类"）。

## 四、常见问题

| 现象 | 原因与处理 |
|---|---|
| 点了同步提示"已是最新" | Pages 部署有约 1 分钟延迟，或 `data/version.txt` 没改（不影响同步判定，判定看文件内容哈希） |
| 提示"内容格式错误" | 文本文件写错了，构建时会指出文件与行号；修正后重新提交 |
| 某个分组没出现在同步结果里 | 它可能已经被你在 App 里删过（删过的分组官方也不会复活） |
| 想让官方更新覆盖我的修改 | 在工作台里把该分组的名称/内容改回官方样子，或点「恢复官方内容」 |
| 新加的汉字没有笔顺动画 | 笔顺数据联网时从 CDN 取，离线只有内置的 115 字；联网状态下会自动补齐 |

## 五、什么时候才需要发版

只有**改功能代码**（比如加新玩法、改界面）才需要发新版本。改学习内容永远不需要发版。
