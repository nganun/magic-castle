# 儿童无障碍场景语音互动设计规范

**文档状态**: Approved / Ready for Implementation  
**日期**: 2026-10-31  

---

## 1. 目标与背景

针对 3~6 岁尚未识字或识字量较少的幼儿，界面上的纯文字说明（如“还差 5 分钟”、“沉睡中”、“专属币可用”）无法被有效理解。
为了提供真正符合幼儿心智模型的“所点即所听（Click-to-Speak）”无障碍体验，在全应用核心交互中融入**情境化语音伴读与引导机制**：
- **触发原则**：严格遵循用户选定的**「仅在点击交互时语音提示」**，不主动发声干扰，但在孩子好奇点击任意卡片、按钮、徽章或不可用状态时，由露娜给出温暖贴心的真人语音解释。
- **个性化**：所有语音动态代入孩子称呼 `childName()`（如“荆宝”）。

---

## 2. 语音映射矩阵（Voice Action Matrix）

| 交互目标 | 触发场景 / 条件 | 语音文案 |
| :--- | :--- | :--- |
| **转盘入口按钮** | 有转盘机会（`spins > 0`） | `“太棒啦，${childName()}！你有 ${spins} 次转盘机会，快来抽大奖吧！”` |
| **转盘入口按钮** | 无机会（`spins === 0`） | `“今天已学 ${mins} 分钟，再认真学 ${remain} 分钟，就能来转大转盘啦！”` |
| **游戏币状态槽** | 任何时候点击 | `“这里是你的魔法游戏币，转动大转盘就能拿到魔法币来点亮小游戏哟！”` |
| **沉睡游戏卡片** | 处于沉睡状态不可玩 | `“【${gameName}】还在睡觉呢，去转动大转盘，拿到魔法币就能把它唤醒啦！”` |
| **已点亮游戏卡片** | 处于点亮状态开玩前 | 伴随投币音效并播报：`“【${gameName}】已经为你点亮啦，快来玩吧！”` |
| **转盘内部扇区** | 点击任意扇区查看 | 念出扇区奖品名称与用途（如：`“这是水果切切乐的专属门票哟”`） |
| **顶部魔法星** | 点击魔法星按钮 | `“${childName()} 现在拥有 ${stars} 颗魔法星！点击去看星光奇遇之路吧！”` |
