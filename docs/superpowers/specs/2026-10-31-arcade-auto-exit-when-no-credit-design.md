# 小小游戏机无游玩资格自动倒计时退出规范

**文档状态**: Approved / Ready for Implementation  
**日期**: 2026-10-31  

---

## 1. 目标与规则

当小朋友进入小小游戏机大厅（`state.screen === 'arcade' && !state.arcadeGameId`）时：
1. **触发判断条件**：
   - 处于非家长模式（`!parentModeEnabled`）；
   - **既没有可用的转盘机会**（`arcadeSpinsAvailable() === 0`）；
   - **手头上也没有任何可玩的通用币或专属币**（`getUniversalCoins() === 0 && 无任何 specificCoins > 0`）。
2. **交互与视觉反馈**：
   - 立即播放温和语音：
     > `“荆宝，今天还没有学习时间来开启转盘哟！先去认真学 10 分钟吧！”`
   - 大厅顶部展示一个可爱的倒计时条与 Toast 提醒：
     > `⏱️ 暂无可用游戏币或转盘机会，5 秒后带你去魔法城堡学习...`
3. **5 秒倒计时与自动退出**：
   - 启动 5 秒定时器（`arcadeDormantExitTimer`）；
   - 倒计时结束后平滑切回课程或首页（`setScreen('lesson')`）；
   - 若用户主动离开大厅（如点击返回或切换屏幕），立即清除定时器防内存泄漏。
4. **特权保护**：
   - 若处于家长模式，或者手头尚有未用完的魔法币，不触发退出。
