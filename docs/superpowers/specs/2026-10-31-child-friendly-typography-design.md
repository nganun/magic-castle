# 儿童友好大字号与视觉易读性重构规范（方案 A）

**文档状态**: Approved / Ready for Implementation  
**日期**: 2026-10-31  

---

## 1. 目标与设计原则
遵循儿童无障碍视觉设计规范（Child-Friendly Typography），消除全站低于 12px 的超小字体与不易识别的细小文本，提升 3~8 岁幼童阅读舒适度与认读效率。

### 核心分级阶梯：
- **底线**：全站儿童端可见文本基线提升至 **>= 13px~14px**，杜绝 7px~10px 的噪点小字；
- **微徽章 / 辅助说明 / 底部导航**：从 10px~11px 提升至 **13px~14px**，搭配 `font-weight: 800`；
- **游戏机大厅与大转盘**：
  - 转盘扇区 Emoji 放大到 **24px~26px**；
  - 扇区文字放大到 **13px~14px**，精简为清晰关键词（如“通用币”、“切切乐”、“小绵羊”、“音乐节”）；
  - 游戏机状态条与副标题由 11px 提升至 **14px~15px**，加粗显示；
- **星光奇遇之路（Roadmap）**：
  - 里程碑标签、序号从 10px~11px 放大至 **13px~14px**；
- **底部常驻导航栏（Nav Bar）**：
  - 文字从 11px~12px 提升至 **13px~14px**，图标与间距微调保证 44px 触控标准。

---

## 2. 改造范围与文件
1. `app.js`：转盘 SVG 扇区文字字号由 `9` 改为 `13`，文字居中精简；
2. `style.css`：
   - 底部导航 `.nav-item span`；
   - 游戏机大厅卡片状态徽章 `.arcade-game-badge`；
   - 游戏机进度与转盘副标题小字 `small`, `.arcade-coin-status small`；
   - 游戏机卡片副标题与标题文字；
3. `styles/screens/roadmap.css`：
   - `.roadmap-node-badge`、`.roadmap-node-label`、关卡指示文字提升至 13px~14px。
