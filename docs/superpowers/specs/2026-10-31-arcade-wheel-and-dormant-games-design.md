# 小小游戏机魔法大转盘与定向点亮机制设计文档

**文档状态**: Approved / Ready for Implementation  
**日期**: 2026-10-31  

---

## 1. 目标与背景

为了让小小游戏机的防沉迷机制更具童趣和正向驱动力，摒弃单调的倒计时掐断，采用 **【学习时长 ➔ 魔法大转盘 ➔ 获得通用币 / 专属游戏币 ➔ 对应游戏点亮】** 的全新互动体系：
1. **沉睡与点亮机制**：
   - 默认状态下，小小游戏机内的全部游戏卡片处于**灰色沉睡（grayscale + opacity .55）**状态，不可点击直接开玩（点击会温馨语音提示“去转大转盘唤醒游戏吧”）。
   - 当获得**专属游戏币（如 🍎 切切乐币）**时，仅对应的游戏卡片**彩色点亮 + 呼吸金边**。
   - 当获得**通用魔法币（🪙 通用币）**时，**全场所有游戏卡片全部彩色点亮**，孩子可任选一款消耗进入。
   - 游戏一局结束后（无论胜负），扣除对应币，若无剩余可用币，卡片恢复灰色沉睡状态。
2. **大转盘触发规则**：
   - 每累计专注学习满 **10 分钟**，获得 **1 次魔法大转盘机会**。
   - 每天最多可获得 3 次转盘机会（即学满 30 分钟达到上限）。
   - 在小小游戏机大厅头部设置醒目的【🎡 魔法大转盘】入口，未达 10 分钟时显示当前进度（如 `已学 6/10 分钟`）。
3. **单局结算规则**：
   - 1 个币 = 畅玩 1 局（约 1.5 ~ 3 分钟），以天然的局数完结作为自然休息节点，不强制秒级掐断。
4. **👑 家长模式特权**：
   - 家长模式下全场保持彩色常亮，免币免转盘畅玩。

## 2. 数据结构设计（`state.arcadeStats`）

伴随日历日期 `todayKey` 自动每日隔离刷新：
```js
state.arcadeStats = {
  ...state.arcadeStats,
  wheelSpinsAvailable: 0, // 当前剩余可抽奖次数（随学习时长累计扣减）
  wheelSpinsGranted: { [todayKey]: 0 }, // 今日已发放的转盘次数（最大 3 次）
  universalCoins: { [todayKey]: 0 }, // 今日持有的通用魔法币数量
  specificCoins: {
    [todayKey]: {
      fruit: 0, // 水果切切乐
      match: 0, // 羊了个羊
      rhythm: 0, // 节奏达人
      whack: 0, // 魔法打地鼠
      memory: 0, // 翻翻乐
      catch: 0, // 接金币
      listen: 0, // 听音找图
      number: 0, // 数字对对碰
    }
  }
};
```

## 3. 大转盘扇区分配（8 个扇区）

1. 🪙 **通用魔法币 ×1** (概率 30%)：全场游戏瞬间全部点亮！
2. 🍎 **切切乐专属币 ×1** (概率 12%)：点亮水果切切乐
3. 🐑 **消消乐专属币 ×1** (概率 12%)：点亮羊了个羊
4. 🥁 **节奏专属币 ×1** (概率 10%)：点亮节奏达人
5. 🐹 **打地鼠专属币 ×1** (概率 10%)：点亮魔法打地鼠
6. 🎴 **翻翻乐专属币 ×1** (概率 10%)：点亮魔法翻翻乐
7. 🪙🪙 **超级幸运！通用币 ×2** (概率 6%)：全场点亮，可连玩两局
8. ⭐ **星光大礼包：魔法星 ×2** (概率 10%)：直接推进星光奇遇之路

## 4. 界面与交互细节

1. **小小游戏机大厅顶部**：
   - 展示大转盘入口按钮：
     - 若 `wheelSpinsAvailable > 0`：大转盘按键剧烈跳动发光，显示 `🎡 有 1 次转盘机会！点我抽奖`。
     - 若 `wheelSpinsAvailable === 0`：显示 `⏱️ 今日已学 X 分钟 · 还差 Y 分钟获得转盘机会`。
   - 资产栏：显示当前拥有的通用币与已点亮的专属游戏。
2. **游戏卡片状态计算**：
   ```js
   function isGamePlayable(gameId) {
     if (parentModeEnabled) return true;
     const universal = Number(state.arcadeStats.universalCoins?.[todayKey] || 0);
     if (universal > 0) return true;
     const specific = Number(state.arcadeStats.specificCoins?.[todayKey]?.[gameId] || 0);
     return specific > 0;
   }
   ```
   - 若不可玩：卡片增加 `.arcade-game-dormant` 类名（滤镜置灰 `filter: grayscale(1) opacity(0.55)`），点击播放提示语音并引导去转转盘或学习。
   - 若可玩：彩色饱满并带有柔和的魔法呼吸光晕（`box-shadow: 0 0 16px rgba(250, 204, 21, 0.6)`），并带有专属券标记。
3. **转盘弹窗（Wheel Modal）**：
   - 优雅的 SVG/Canvas 轮盘动画，点击中间“GO/抽奖”按钮旋转 3.5 秒后停在指定奖品区；
   - 伴随彩带纸与胜利音效（`playSfx('fanfare')`），展示恭喜弹窗并即刻点亮对应游戏卡片。
