# 家长控制中心独立全屏界面（Screen）重构规范

**文档状态**: Approved / Ready for Implementation  
**日期**: 2026-10-31  

---

## 1. 目标与设计原则
告别原狭小局促、需内部滚动的悬浮弹窗（Modal），将【家长小站】升级为与【星光奇遇之路】同级的独立专属全屏屏幕（`#parentScreen`，对应路由 `#parent`）。给丰富的管理功能（学习概览、孩子档案、朗读语速、探险时长、星星恢复、内容工作台、意见记事簿）提供大气舒适的现代设置卡片流体验。

---

## 2. 页面架构与用户旅程

### 1) 验证切入旅程（Parent Gate）
- 用户在任意页面点击顶栏右上角 `🌱 给爸爸妈妈`：
  - **若处于家长模式（`parentModeEnabled`）**：免答题，直接全屏平滑切入 `setScreen('parent')`；
  - **若未处于家长模式**：呼出一个极其轻巧、专注的算术防误触验证弹框（`#parentGateModal`），输入正确答案后，激活家长模式并直接切入 `setScreen('parent')`。

### 2) 全屏界面结构（`#parentScreen`）
- **顶部返回与标题栏（Parent Top Bar / Nav）**：
  - 返回按钮：`‹ 返回魔法城堡`，一键平滑退回此前屏幕（或首页）；
  - 标题：`家长控制中心`；
  - 右侧状态切换：`👑 家长模式生效中` / `退出家长模式` 快捷按钮。
- **分类标签（Tabs）**：
  - `📊 学习概览`：星星数、掌握词数、打卡天数、7 天学习日历、孩子档案切换与新增；
  - `⚙️ 陪伴设置`：全局朗读语速试听、每日探险时长滑块控制；
  - `🛠️ 内容与工具`：星星与饰品一键恢复、学习内容工作台、导入/导出学习记录、重置今天、意见记事簿。
- **布局美学**：
  - 容器居中 `max-width: 800px`，背景为温润护眼的浅紫/米白渐变；
  - 各选项按 iOS/Android 现代设置风格卡片（Grouped Cards）呈现，层次分明，操作触控热区充裕。

---

## 3. 代码与状态流重构
1. **路由与切屏**：
   - 增加 `state.screen === 'parent'`，路由为 `#parent`；
   - 顶栏面包屑与返回导航联动适配；
2. **DOM 结构调整**：
   - 将原 `#parentContent` 从 `#parentModal` 中迁出，移入 `main` 下的新 `<section class="screen" id="parentScreen">`；
   - 原 `#parentModal` 精简保留为仅承载算术小题的 `#parentGateModal`（或重命名类名）；
3. **事件与焦点**：
   - 移除原来的弹窗关闭逻辑，改为标准全屏返回。
