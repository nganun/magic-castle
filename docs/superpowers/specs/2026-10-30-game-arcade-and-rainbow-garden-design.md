# 魔法城堡：小小游戏机扩充与彩虹花园重构设计方案

## 1. 概述与背景

用户提出五项核心升级需求：
1. **小小游戏机扩充与精简**：
   - 接入 `/Users/qk/code/game` 下的全部 8 款小游戏（打个螺丝、消个水果、一箭又一箭、羊了个羊、抓大鹅、拼拼豆、兔了个兔、鱼了个鱼）；
   - 移除原有的「箭头快跑」游戏；
   - 将现有「数字泡泡」游戏由 5 关扩展到 10 个关卡，难度平滑递增；
   - 修复「接水果」在移动端左右滑动有时不灵敏的问题。
2. **彩虹花园重构（综合常识与认知学习）**：
   - 将原硬编码的「色彩魔法」升级为与「汉字图书塔」结构和形式一致的认知学习模块；
   - 文本内容数据驱动，基于 `data/misc/` 目录组织分组与词表（首期内置「形状」与「颜色」两组）；
   - 用户与家长后续可通过文本文件或手机工作台随时扩展更多认知分组（如新增颜色、形状或常识分类）；
   - 学习形式采用卡片式认知流：大图展示（形状/色块）、汉字词语、TTS 真实发音，点击「继续」翻阅卡片；
   - 提供与汉字图书馆一致的分组全屏卡片库弹窗，支持分组 Tab 切换、网格卡片矩阵、点选发音、定向跳转学习和一键连续播放。
3. **内置 Issue / 意见与想法记事簿**：
   - 在家长小站提供「意见与想法 / 提 Issue」专属入口与便捷弹窗；
   - 支持本地记录 Bug 反馈和新想法，带状态管理（未处理 / 已完成）；
   - 支持一键导出、复制为 GitHub Markdown 格式，便于随时记录并在后续迭代中查阅。

## 2. 小小游戏机升级设计

### 2.1 游戏清单变更
- **移除**：`arrows`（箭头快跑）。
- **优化**：`numbers`（数字泡泡）：
  - 关卡上限由 5 关改为 10 关；
  - 关卡梯度：
    - 第 1 关：0~5（3 泡泡）
    - 第 2 关：0~10（3 泡泡）
    - 第 3 关：0~10（4 泡泡）
    - 第 4 关：0~15（4 泡泡）
    - 第 5 关：0~20（5 泡泡）
    - 第 6 关：0~30（5 泡泡）
    - 第 7 关：0~50（6 泡泡）
    - 第 8 关：0~60（6 泡泡）
    - 第 9 关：0~80（7 泡泡）
    - 第 10 关：0~100（8 泡泡）
- **优化**：`catch`（接水果）滑动响应修复：
  - 将滑动监听扩展至 `document` 全局，并在 `touchstart`/`touchmove` 中阻止默认滚动行为；
  - 改善触摸坐标向 Canvas 画布的相对映射，消除边界出框导致的卡顿/失灵；
  - 增加对屏幕左右边缘区域拖拽的边界保护。
- **新增 8 款小游戏**：
  1. `screw`：打个螺丝（收纳/物理拼图）
  2. `fruitbox`：消个水果（卡槽三消收纳）
  3. `arrow-shoot`：一箭又一箭（物理射击）
  4. `sheep`：羊了个羊：星球（经典三消堆叠）
  5. `goose`：抓大鹅（3D 三消收纳）
  6. `beads`：快乐拼拼豆（像素与拼豆解谜）
  7. `xlegex`：兔了个兔（简化版萌兔三消）
  8. `yulegeyu`：鱼了个鱼（鱼类主题三消解谜）

### 2.2 小游戏接入与运行机制
- 存放路径：`vendor/mini-games/<game-id>/`。
- 构建与资源准备：
  - `minigame-everyday` 源码直接放入并调整为纯静态相对路径；
  - `xlegex` 与 `yulegeyu` 编译构建为纯静态 dist 资源存入对应目录；
  - 确保小游戏内的 js/css/assets 引用皆为相对路径，支持无服务/file/沙箱环境离线加载。
- 运行时容器：
  - 注册在 `app.js` 的 `VENDOR_MINI_GAMES` 中；
  - 使用统一的 iframe 沙箱与自适应视口加载；
  - 顶部常驻返回按钮与游戏标题栏，退出时自动销毁 iframe 释放内存与音频。

## 3. 彩虹花园（综合认知模块）设计

### 3.1 文本内容源规范（`data/misc/`）
沿用项目的解耦设计，内容定义在纯文本中：
- 分组 1：`data/misc/基础/形状.txt`
  ```txt
  # id: shapes
  # image: true
  三角形
  正方形
  长方形
  圆形
  半圆形
  梯形
  ```
- 分组 2：`data/misc/基础/颜色.txt`
  ```txt
  # id: colors
  # image: true
  红色
  蓝色
  白色
  黑色
  绿色
  黄色
  紫色
  ```

### 3.2 架构与数据流
1. **内容构建扩展**：
   - `features/content-files.js` 将 `CONTENT_KINDS` 扩展为 `['english', 'hanzi', 'recital', 'misc']`；
   - `misc` 词条使用汉字及词语安全校验（支持 1~8 字的多字词组）；
   - `scripts/build-learning-content.mjs` 自动扫描 `data/misc/`，生成 `default-content.js` 和 `dist/content/misc/` 快照。
2. **应用集成与主题构建**：
   - 在 `MAP_META` 中将 `color`（彩虹花园）绑定到 `misc` 内容源；
   - `app.js` 支持 `activeContentGroup('misc')` 及 `contentGroups('misc')`；
   - 动态根据激活分组（如“形状”或“颜色”）生成主题数据。
3. **图形渲染体系**：
   - 提供专属的矢量 SVG / 绘图渲染器：
     - 形状类：动态或预置精准绘制三角形、正方形、长方形、圆形、半圆形、梯形等；
     - 颜色类：渲染饱满可爱的魔法颜色光球与色块卡片；
     - 扩展类：若暂无特定图形，使用优美渐变的主题卡片展示。

### 3.3 交互与学习流
1. **主学习页（卡片式循序认知）**：
   - 每次展示当前项目（如“三角形”）：
     - 顶部：当前分组名与进度指示（例如：形状 · 1 / 6）
     - 中部：大图形展示（清晰标准的几何图形或纯净色块）
     - 下部：汉字词条（“三角形”）、拼音、朗读喇叭按钮（点击播放 TTS 发音）
     - 底部操作栏：【上一个】、【再听一遍】、【继续 ➜】
   - 点【继续】自动进入下一个卡片并自动朗读；
   - 最后一个学完时，弹出庆祝动画并点亮城堡星星奖励。
2. **分组全屏卡片库弹窗（对标汉字图书馆）**：
   - 点击顶部「全部认知卡片」打开弹窗；
   - **顶部 Tab**：展示所有分组（“形状”、“颜色”及后续添加的分组），点击无缝切换；
   - **网格矩阵**：卡片网格自适应展示组内全部条目，每张卡片包含缩略图形、词语、已掌握/正在学状态；
   - **交互**：
     - 点击卡片自身：高亮并朗读发音；
     - 点击「学这个」：立即以此卡片为起点进入学习；
     - 底部【连续朗读】：按顺序自动依次播放每个卡片发音。

## 4. 内置 Issue 记事簿与反馈入口设计

### 4.1 入口位置
- 在 App 的「家长小站」→「内容与工具」中新增 **「记录想法与 Bug / 提 Issue」** 快捷按钮；
- 界面常驻：在家长小站顶部操作栏亦提供快速访问图钉，避免繁琐层级。

### 4.2 功能与交互
- 弹窗包含两大部分：
  1. **新建 Issue**：
     - 类型选择：🐛 Bug 反馈 / 💡 新想法灵感 / 🛠️ 体验优化；
     - 标题输入；
     - 详细内容（可记录复现步骤或详细设计建议）；
     - 当前环境自动附加（App版本、屏幕尺寸、当前学习者、当前页面）。
  2. **历史 Issue 列表**：
     - 列表展示所有已记录条目，带时间戳和状态徽标（待办 / 已完成）；
     - 支持点击切换完成状态；
     - 提供「复制全部为 Markdown」或「导出 JSON」，方便直接粘贴到 GitHub Issues 或发给 AI 助手进行新一轮开发。
