# 汉字笔顺描红 (P0) 与即时正向反馈强化 (P1) 设计文档

## 1. 概述与目标

本项目为《魔法城堡》少儿学习应用的核心交互升级，聚焦于解决两个关键诉求：
1. **P0（教育厚度升级）**：将汉字学习从单一的“看字、听音”升级为“动笔书写”，引入标准楷体规范笔顺演示与手指描红互动。
2. **P1（儿童成就感强化）**：在书写完成、关卡掌握与学完字表时，提供充满仪式感的全屏彩带烟花与纯前端 Web Audio 萌系合成音效，强化正向激励。

---

## 2. 界面与交互设计

### 2.1 字体与视觉标准
- **楷体规范**：所有涉及汉字字形、字帖、田字格背景字、发音示范等位置，严格使用标准楷体字体栈：
  `font-family: "STKaiti", "KaiTi", "BiauKai", "楷体", serif;`
- **田字格/米字格设计**：
  - 经典米字格红/灰虚线辅助线：包含中心十字线与对角虚线，方便儿童观察汉字间架结构；
  - 暖色童趣纸张底色（`#fffdf7` / `#fcf4e4`），搭配柔和圆角卡片边框。

### 2.2 汉字书入口（#hanziLearnMarkup）
- 在“会说话的书页”汉字下方，增加快捷功能按钮：
  - `[ ✍️ 练习写字 (笔顺描红) ]`
  - 点击后唤起全屏居中的**田字格写字台弹窗（#hanziWriterModal）**。

### 2.3 田字格写字台弹窗（#hanziWriterModal）
- **顶部工具条**：
  - 词组字签切换区（多字词支持）：
    - 针对当前词语（例如“面粉”、“小猫”），顶部展示每个单字的字标签：`[ 面 ✓ ] [ 粉 ✍️ ]`；
    - 支持点击任意字切换书写目标；
    - 单字写完自动跳到下一字；全部字写完触发整词完成大庆祝。
  - 右侧：关闭返回按钮（`×` 或“返回”）。
- **中央田字格书写区**：
  - 正方形自适应画布（桌面端 300×300px，移动端屏幕 260~300px）。
  - 基于集成向量数据驱动的笔画笔形，严格遵循教育部标准楷体楷书规范。
- **操作面板**：
  - **🎬 演示笔顺**：自动一笔一划动态演示，带有笔锋运动轨迹；
  - **✏️ 手指描红**：开启练习模式，给出半透明灰色描红底字，孩子按笔画顺序手写；
  - **🔄 重新写**：清空书写内容，从第一笔重新开始；
  - 笔画进度指示条：例如“第 3 笔 / 共 5 笔”。

## 3. 互动逻辑与反馈系统

### 3.1 描红判定机制
- **正确判定**：孩子沿笔画方向与笔顺划过，判定通过；播放清脆的“叮”声，笔画变为深墨色，笔数计数 +1。
- **错误纠偏**：若笔顺错误或偏离轨迹，笔画呈现轻微红色抖动，发出温和的低音提示，引导重新书写该笔。
- **多端触控**：支持鼠标划动与手机触摸屏（Touch/Pointer），针对触摸事件优化 `touch-action: none` 防止页面拖动。

### 3.2 即时正向反馈（P1）
- **单字写完反馈**：
  - 顶部字标签变绿并打勾 `✓`；
  - 播放清脆的赞许音效，田字格微光闪烁；
  - 若还有后续字，延迟 400ms 自动平滑切换至下一字并开始描红。
- **整词完成 / 关卡过关大庆祝**：
  - **全屏彩带纸屑（Confetti & Star Particles）**：
    - 基于轻量原生 Canvas 实现（0 额外外部依赖）；
    - 随机喷射红、黄、紫、粉、蓝各色微粒与旋转五角星，伴随重力与飘落摆动衰减；
    - 动画持续 2 秒后自动停止并释放 Canvas 资源，保持性能轻量。
  - **Web Audio 萌系合成音效（Audio Synthesis）**：
    - **单笔写对**：880Hz -> 1320Hz 双正弦波清脆叮咚（Bell/Ding）；
    - **写错提示**：220Hz 三角波短促温和低音（Soft Bonk）；
    - **全词完成 / 闯关成功**：大三和弦连续琶音（C5 - E5 - G5 - C6）加上清亮泛音，欢呼感拉满；
    - 全程采用浏览器内置 Web Audio API 振荡器生成，零下载等待，移动端 0 延迟；
    - 自动挂载 `touchstart` / `click` 全局首次手势监听，调用 `audioCtx.resume()`，确保 iOS Safari 及 Android 静音策略下安全唤醒。

## 4. 离线支持与数据获取策略

1. **笔画矢量数据加载与缓存（Char Data Strategy）**：
   - 内置离线回退机制：优先尝试本地离线预置字库数据或 CacheStorage 缓存；
   - 若本地无缓存，通过 `charDataLoader` 获取单字矢量定义（单个字数据仅 1~2KB），并自动持久化至本地 `localStorage` / `CacheStorage`，确保一次加载后永久离线可用；
   - 若处于完全离线且无数据情况，优雅回退至田字格楷体大字直接描画模式，保证界面不崩溃。
2. **离线 PWA 支持（Service Worker）**：
   - 将新增的 `vendor/hanzi-writer/hanzi-writer.min.js`、`features/confetti.js`、`features/audio-sfx.js` 写入 `service-worker.js` 的 `APP_SHELL` 静态缓存清单。

## 5. 架构与文件变更

1. **`vendor/hanzi-writer/hanzi-writer.min.js`**：
   - 引入成熟稳定的单文件独立运行版笔顺互动库。
2. **`features/confetti.js`**：
   - 原生 Canvas 粒子烟花与五角星爆炸特效模块，对外暴露 `triggerConfetti()`。
3. **`features/audio-sfx.js`**：
   - 基于原生 `AudioContext` 的合成音效发生器，提供 `playSfx('ding')`, `playSfx('wrong')`, `playSfx('fanfare')`，内置移动端手势自动解锁机制。
4. **`index.html`**：
   - 增加 `#hanziWriterModal` 弹窗结构。
5. **`style.css`**：
   - 增加写字台样式、田字格/米字格辅助网格、字签切换按钮与描红画布样式，严格遵循楷体规范。
6. **`app.js`**：
   - 汉字书增加写字入口按钮；
   - 实现写字弹窗的多字切换、演示笔顺、描红进度判定与整词完成联动。
7. **`service-worker.js` & `scripts/build-web.mjs`**：
   - 将新资源加入 PWA 预缓存清单并确保打包脚本同步。

## 6. 测试与验收标准
- [ ] 点击汉字书“练习写字”，弹出田字格写字台。
- [ ] 遇到多字词语（如“面粉”）时，顶部可清晰查看每个字并在单字间自由切换，写完自动推进。
- [ ] 汉字与所有书写示范文字均以规范楷体展现。
- [ ] 点击“演示笔顺”，笔画按正确笔顺依次动态呈现。
- [ ] 点击“手指描红”，在手机/桌面上可用手指或鼠标按笔顺描红，并伴随即时音效。
- [ ] 写错有纠错提示，写对整词后触发全屏彩带爆炸特效与胜利琶音。
- [ ] 移动端运行流畅，手写跟手无卡顿，无网络离线情况下体验稳定。
